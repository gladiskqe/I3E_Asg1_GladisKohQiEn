Candyland Obby game
the user audience intent and purpose is to allow user to try the different stages with progressive diffculities and have fun while playing the game.The game allows both the obby lovers which like to overcome obstacles to run their brain and collectors which tend to collect all the items.The stages gets more challenging as you continue and towards the end you might get instantly killed. I've also added neccessary collectible items such as crystal and coins to unlock doors. Click "E" to interact with Coins, Crystal, Door and Exit. Crystal is at the top. White colour is safe.

Instructions: 
Go to the top of the ball obby and collect the crystal to unlock the door
Pick all the coins along the way
White colour is safe
Collect all 15 coins to exit

Use unity and Visual code to run

External source code used: Chatgpt, Co-Poilot, Claude, Youtube.

Design Process
The overall colour scheme is candyland which is why i used pink, red, white, grey and wood.
There is lava which decreases your health.
There is a stage that when you pick the wrong colour, you get instant killed.
